## Why

当前面板把界面文字与技术数据都设为等宽字体，区块间距较小，流量曲线与指标重叠，模式和页面导航的层级不清晰。规则、连接、日志、系统页和编辑弹窗也缺少一致的分组样式。

用户要求先推送已有代理提供商管理变更，再参考所提供的五阶段计划开始 UI 优化。本次采用推荐的 376pt 面板、双列快捷磁贴，完整覆盖五阶段，并通过原生视图渲染验收。

## What Changes

- 系统界面字体与技术等宽字体分开使用，统一间距、圆角、卡片、图标底托、微标签和延迟胶囊。
- 更新主面板头部、水平模式分段控件、页面导航与页脚，沿用屏幕约束下的动态高度。
- 流量指标与平滑面积曲线分层；系统代理与 TUN 使用并排磁贴，配置切换和终端复制使用分组列表。
- 提供商与策略组使用内嵌卡片；测速和测量时间按悬停或键盘焦点逐步显示，保留可访问操作。
- 规则、连接和日志统一列表样式与置顶过滤工具卡片，系统设置采用分组卡片。
- 编辑和诊断弹窗共用头部、可滚动内容及固定操作栏，统一表单和代码预览。
- 新文本同时维护中文与英文，导出五个页面及各类弹窗的浅色、深色预览。

## Capabilities

### New Capabilities

- `native-panel-presentation`: 原生面板的设计系统、页面导航、指标布局及编辑与诊断弹窗。

### Modified Capabilities

无。代理、规则、配置保存和核心控制的业务能力沿用现有实现。

## Impact

`Core/UI`、`Views/MenuBar`、本地化、视觉渲染测试和开发说明。复用现有 SwiftUI / AppKit，不增加第三方 UI 依赖。持久化仍使用原生 mihomo 文件，运行态操作和订阅覆盖规则保持原有语义。
