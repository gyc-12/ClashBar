## Context

运行态 all 包括动态订阅节点，不能直接写回 proxies。节点历史保留四次测量；面板已有原子保存、冲突保护、备份和核心重载事务。

## Decisions

- 只改本地原生显式成员，保持 use、过滤器和其他字段；支持调整成员顺序并在按需清空显式成员时移除空 `proxies` 键。删除检查父组、规则与下载策略等依赖；核心停止仅存文件，运行中保留重载验证及回滚。整份订阅覆盖仍可能丢失本地改动。
- 折叠只读节点本身的历史，保护当前成员和子组；不改路由、后台测速或订阅。不把重复轮询或接口不可用当作多次超时。
- 按组网络连通性经指定组调用 mihomo URL 测试并要求 `expected=200-399`，避免 403 拦截页误报可达；仅报告网络可达性。Gemini 和 ChatGPT 地区可用性使用当前控制器实际公布的 mixed / HTTP / SOCKS 端口（将 `0.0.0.0`/`::` 归一化为 loopback）请求匿名页面，按核心实际规则分流。不修改组选择、配置或系统代理，不取浏览器 Cookie，也不回退到面板直连。
- Gemini 地区检测兼容旧数组标记 `45631641,null,true` 与新对象标记 `"45631641":true` 以及三字母地区码 `,2,1,200,"XXX"`，并允许足够重定向次数以到达登录页后回退检测公开首页的地区拒绝信号。优先识别可见的地区拒绝文案；不把 HTTP 200、普通登录页、验证码或非拒绝名单的地区码单独当成支持证据。ChatGPT 地区检测结合 `/cdn-cgi/trace` 地区码与匿名首页状态及拒绝文案判定，不把 403/验证页当作可用。
- 新订阅默认值保持通用：更新间隔 `3600` 秒（支持设为 `0` 手动更新）、健康检查默认启用 `https://cp.cloudflare.com`（每 `300` 秒）、下载策略 `DIRECT`、默认 User-Agent 列表、前缀默认为空（空前缀不写 `override.additional-prefix`）；`path` 自动唯一。编辑已有 HTTP 订阅时允许重命名（同步更新 `proxy-groups[].use` 及禁用布局元数据，校验重名与保留名）并修改所有上述选项，同时保留未触及的自定义字段和未变链接的现有 `path`。
- 仅对直连新增源加载失败重试一次，优先匹配名为 `proxy`（不区分大小写）的组，否则尝试常见主代理选择组；独立探针在不修改真实文件的前提下，把当前运行态各选择组已选成员（若位于显式 `proxies` 中）置顶，避免探针误落到首位死节点或直连。成功后保存实际验证过的下载策略，两次失败不改原文件。
